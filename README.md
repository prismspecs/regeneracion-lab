# Regeneración Lab - WordPress Theme

This repository contains the development assets and design prototypes for the **Regeneración Lab** custom WordPress theme.

## Project Overview

Regeneración Lab is a digital humanities and Indigenous studies platform hosted by UCSB. This theme is designed to reflect the aesthetic of the turn-of-the-century Mexican anarchist newspaper *Regeneración* (1900-1918), blending historical typography with modern, accessible web design principles.

## Key Features

-   **Theme Name:** Regeneración Lab Theme
-   **Platform:** WordPress (hosted on Pantheon)
-   **Design Aesthetic:** Minimal, text-focused, with nature-evoking palettes (river/water justice themes) and "anarchist newspaper" typography.
-   **Prototypes:** The repository includes several versions (`version1` through `version6`) of static HTML/CSS/JS prototypes exploring different layouts, navigation styles (SPA, scroll storytelling), and archive interfaces.

## Structure

*   `/version[1-6]`: Static design prototypes serving as the foundation for the WordPress theme templates.

## Development Status

The project is currently in the prototyping phase, converting static designs into a functional WordPress theme structure.
